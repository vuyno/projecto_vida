# Projecto Vida 🇦🇴
### Preparação e Resposta a Desastres Causados pela Chuva

> **Localização:** Huíla, Angola  
> **Foco:** Resiliência Comunitária, IA e Alerta Precoce

## 📋 Sobre o Projeto
O **Projecto Vida** é uma iniciativa tecnológica e comunitária para reduzir a vulnerabilidade de zonas rurais em Angola a desastres naturais. O sistema combina sabedoria local com **Inteligência Artificial** para prever inundações e coordenar brigadas de resposta.

## 🚀 Funcionalidades da Interface
- **Dashboard em Tempo Real:** Monitorização de pluviometria, níveis de rios e vento.
- **IA Preditiva:** Análise de risco baseada em dados históricos e atuais.
- **Sistema de Alerta:** Indicadores visuais (Verde, Amarelo, Vermelho) para a comunidade.
- **Gestão de Brigadas:** Área para voluntários reportarem incidentes.

## 🛠 Tecnologias (Conceito)
- **Frontend:** HTML5, CSS3 (Glassmorphism UI), JavaScript.
- **Backend (Planeado):** Python/Django para processamento de IA.
- **Integração:** APIs de sensores meteorológicos e Twilio (SMS).
